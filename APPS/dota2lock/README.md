# dota2lock

GTK3-based C utility that blocks Dota 2 on weekdays and allows play on Saturday and Sunday.

## Build

```bash
make
```

## Run

```bash
./dota2lock
```

Useful modes:

```bash
./dota2lock --once
./dota2lock --dry-run
./dota2lock --interval 10
```
